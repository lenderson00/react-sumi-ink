# react-sumi-ink

Sumi-e ink fluid layer for React (Rust WASM + WebGL2).

```tsx
import { InkStage, useInk, InkButton } from 'react-sumi-ink';

<InkStage preset="koi" mode="trail">
  <InkButton>Splash</InkButton>
</InkStage>;
```

See the [repo README](https://github.com/lenderson00/react-sumi-ink) for install, Next.js notes and performance.
